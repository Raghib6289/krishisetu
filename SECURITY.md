# Security Policy

## Supported Versions
Security updates are actively maintained on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We take the security of KrishiSetu and its users very seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please send an email with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

to the project maintainer: **raghib@krishisetu.com** (or open a private security advisory on GitHub).

We will acknowledge receipt within 48 hours and work with you on a patch before public disclosure.
